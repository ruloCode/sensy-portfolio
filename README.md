# SENSY — portafolio artístico 2025

Sitio estático (HTML + CSS + JS sin dependencias) del portafolio de Sensy (Lina Forero), rapera de Bogotá.

- `index.html` · `styles.css` · `main.js` — la página.
- `assets/` — imágenes en WebP a 800/1600 px (originales mejorados con upscale).
- `SENSY-portafolio-2025.pdf` — la versión en diapositivas.

Los enlaces a Spotify / YouTube / Instagram se configuran en `LINKS` al inicio de `main.js`.
